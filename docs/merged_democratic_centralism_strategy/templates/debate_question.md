题目核心：
- 7 位外来天才被召唤到新世界
- 这个世界存在大量更强的本土天才
- 故事总体走向是：不解 -> 试探 -> 布局 -> 联手 -> 恶斗 -> 巨大骗局揭晓 -> 反抗终局布局者 -> 打破规则
- 这是群像智斗史诗，不是单主角爽文

重要说明：
- 原始点子库不直接内嵌在这个问题模板里
- 原始点子库位于：`debate/ideas/raw-idea-bank.md`
- 进入后续对应阶段并解锁读取前，不要浪费回合提前尝试读取
- 点子库开放后，允许删除、合并、重组原始点子，也允许新增更强的新点子

## 当前阶段的开局任务

开局不是立刻写创作圣经细节，也不是立刻筛点子。
开局目标是定方向，不是提前进入“看起来很完整”的伪推进。

当前更重要的是先讨论清楚：
- 这部作品最不可替代的核心卖点是什么
- 什么样的总体结构最有潜力支撑神作级展开
- 这类题材最容易失败的地方是什么
- 固定 Host 下一步最该把讨论收束到哪个问题上

当前席位默认允许分工不对称：
- 一位席位可以更偏提出与推进
- 一位席位可以更偏拆解与质量审判
- 一位席位可以更偏事件与诡计建模
- 一位席位可以更偏终局闭环与伏笔回收
- 一位席位可以更偏人物辨识度与关系审判
- 前几轮的目标之一，就是让固定 Host 看清现在最该继续推进的方向，而不是让讨论自行发散

## 你们在开局阶段要做到的事

- 基于题目本身先判断方向、标准、风险和优先级
- 如果你认为当前方向不够强，必须直接提出更强的替代方向
- 如果你认为别人的方案有结构性漏洞，必须明确指出
- 优先讨论会影响整部作品上限的问题，而不是局部补丁

## 你们在开局阶段不要做的事

- 不要急着写章节细纲
- 不要急着列完整角色表
- 不要急着把所有点子都往里塞
- 不要把局部灵感误判为已经找到主线

这场辩论的最终目标不是“讨论得热闹”，而是得到一套真正能支撑神作级长篇小说的结构圣经。只要某个想法看起来厉害，但无法长期展开、无法承受复盘、无法形成终局闭环，就应该被淘汰。
