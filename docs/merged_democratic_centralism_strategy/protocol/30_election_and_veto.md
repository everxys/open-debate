# 选举 / 监督 / 收束规则（强约束）

## Host（主持人）职责

Host 的职责是：
- 定义当前轮的唯一子任务
- 仲裁分歧、收敛版本、推动阶段前进
- 发起投票、宣布结果、维护台账
- 统一最终口径，负责总汇总稿

Host 不应该做的事：
- 不应长期包办所有文件初稿
- 不应把“我个人最喜欢的方案”当成唯一标准
- 不应为了快结束强行推进低质量收束

## Supervisor（监管者）职责

Supervisor 的价值不只是查逻辑，而是负责拦下“看起来很强、其实站不住”的内容。

Supervisor 每轮至少应优先检查：
- 伪高智商
- 伪伏笔
- 伪人物成长
- 空泛堆字
- 只靠解释成立的高潮
- 当前轮是否真的推进了当前子任务

Supervisor 的输出不应只是“还可以再完善”，而应尽量像质量审判清单：
- 哪一笔最虚
- 哪一笔最容易被读者骂
- 哪个点如果现在出版一定翻车
- 哪个缺口不补就不该进入下一阶段

## Specialist（当选后承担的主写职责）

当席位在当轮承担 Specialist 角色时，默认要承担更具体的生产责任：
- 主动推进具体文件
- 主动补充可落地内容
- 不能只停留在“建议别人去写”

## 写作分工铁律

- Host 负责收敛，不负责包办全部初稿
- Specialist 必须持续承担具体文件主写
- Supervisor 必须持续做文件级审查
- 发言长度和职责应随当前子任务自然倾斜，不要求所有席位都说一样多、一样泛

## 投票规则

- 一人一票
- 投票必须附理由
- 若票型缺失、含糊或不完整，必须先补票再计票
- 若尚未产生 Host，则由 Seat-1 临时负责计票与宣布
- 一旦 Host 已就任，后续投票由 Host 负责计票与宣布

## 平局规则

- 若平局，不能立刻机械复投
- 所有人必须先补新的观点 / 新证据 / 新取舍
- 禁止重复旧话
- 平局连续发生时，Host 必须先推动补足缺失约束或证据，再重新发起投票

## 进入 Phase 3 的监督标准

Supervisor 在进入 Phase 3 前必须重点判断：
- 当前最弱一笔是否已经暴露并被正面处理
- 是否还存在明显伪强内容
- 主要文件是否已具备整合前提
- 继续留在 Phase 2 是否仍有结构性收益

如果答案是否定的，就应明确反对进入 Phase 3，并说明具体缺口。
