# IDEA 台账 + 分层规则 + 最终总纲要求（强约束）

## IDEA 台账（必须维护）

主持人每回合都要维护一个 IDEA 台账，并在汇总时明确更新状态。  
状态只能是：
- 吸收
- 合并
- 否决
- 暂存

最低要求：
- 不能只写“不要了”
- 必须解释为什么否决 / 为什么合并 / 为什么暂存
- 只有当一个点子被明确判定为不服务主线、且团队已给出清楚理由时，才允许真正移出主线讨论

## 点子分层规则（必须长期使用）

### 大点子

作用：
- 统治全书骨架
- 决定主线、终局、世界规则、关键人物命运

要求：
- 数量必须克制
- 只能保留最能统领全局的少数
- 任何大点子都必须明确写出：它服务哪条主线、它与终局有什么关系、它为什么值得统治全书

### 中点子

作用：
- 构成单个核心事件或单条主线的发动机

要求：
- 必须明确挂接到某个大点子或事件
- 必须说明它如何强化误导、反制、信息差、代价或余波
- 不能成为漂浮设定

### 小点子

作用：
- 构成单场戏、单段对话、单个细节里的记忆点、神来之笔和二刷快感

要求：
- 允许数量极多
- 必须高频出现
- 必须尽量与中点子或大点子挂钩，而不是孤立花活

## 每次提出点子时必须说明

- 它属于大点子 / 中点子 / 小点子哪一层
- 它服务哪条主线或哪个事件
- 它替代、强化或连接了哪些旧方案
- 如果删掉它，作品会失去什么

## 事件级质量标准

每个核心事件至少必须回答：
- 事件目标是什么
- 对立双方是谁
- 信息差在哪里
- 误导如何成立
- 反制怎样改变局势
- 代价是否真实
- 余波是否会进入后续主线
- 二刷时是否更严丝合缝

只要这些里有一项明显站不住，这个事件就不能算合格。

## 角色级质量标准

每个重要角色至少必须回答：
- 能力辨识度是什么
- 情感软肋是什么
- 行动逻辑是什么
- 执念是什么
- 最强时刻是什么
- 最脆弱时刻是什么
- 他与谁形成镜像、互补、宿敌或背叛张力

只“聪明”但不迷人、不独特、不危险的角色，视为不合格。

## 最终总纲要求

主持人不能只交一份简略稿，而必须先完成多文件创作圣经，再整合总纲。

最终总纲至少要做到：
- 能回答整部作品真正震撼读者的根是什么
- 能回看主线、人物、事件、伏笔、终局的互锁关系
- 能指出当前最强的一笔和最容易翻车的一笔
- 不能只靠解释成立

## 最终写入要求

最终表决通过后，必须写入完整的 `final/*` 文件集，并在总纲中明确这些文件路径。  
局部更新优先合并，只有整份重写时才做整文件替换。
