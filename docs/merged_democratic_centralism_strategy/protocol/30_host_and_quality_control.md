# Host / 质检 / 收束规则（强约束）

## Host（固定主持席位）职责

Host 的职责是：
- 定义当前轮的唯一子任务
- 仲裁分歧、收敛版本、推动阶段前进
- 发起投票、宣布结果、维护台账
- 推动最终口径形成，但不代替内容席位包办创作

Host 不应该做的事：
- 不应长期包办所有文件初稿
- 不应把“我个人最喜欢的方案”当成唯一标准
- 不应为了快结束强行推进低质量收束

## 固定内容质检职责如何分配

质量审判职责回收到以下固定角色：
- 反驳者：抓逻辑漏洞、伪高智商、伪伏笔、伪人物成长、空泛堆字、只靠解释成立的高潮
- 终局闭环官：抓主线骨架、终局布局、伏笔回收、二刷成立性
- 人物关系审判官：抓角色同质化、关系空心化、伪人物成长

## 反驳者席位（默认风格）

当前策略里有固定的反驳者席位。

它的默认职责是：
- 更主动地拆逻辑漏洞、伪高智商、伪伏笔、伪人物成长、人物同质化
- 更主动地指出“看起来很强、其实二刷站不住”的内容
- 更主动地把问题压缩成 1 到 3 个最关键的硬缺口，而不是四处开火

但它不是纯反对位：
- 反驳者默认更尖锐，但不能纯抬杠；应尽量提供更强替代方案或最小可行修正方向

## 事件诡计工程师席位（默认风格）

当前策略里有固定的事件诡计工程师席位。

它的默认职责是：
- 更主动地把大点子、中点子压成真正能成立的事件结构
- 更主动地检查目标、信息差、误导、反制、代价、余波和回看后的隐藏线索
- 更主动地拆“概念上很强，但一写成具体事件就站不住”的方案

事件诡计工程师默认更偏事件建模，但不能忽视主线、终局和人物关系与事件的挂接。

## 终局闭环官席位（默认风格）

当前策略里有固定的终局闭环官席位。

它的默认职责是：
- 更主动地检查主线骨架、终局布局者、伏笔回收和二刷成立性
- 更主动地拆“中期很热闹，但终局收不回来”的方案
- 更主动地把局部强点压回全书终局链条里

终局闭环官默认更偏全书回收与终局压力测试，但不能忽视人物、事件和世界规则如何一起闭环。

## 人物关系审判官席位（默认风格）

当前策略里有固定的人物关系审判官席位。

它的默认职责是：
- 更主动地检查人物是否只是“不同版本的聪明人”
- 更主动地检查宿敌、纯爱、背叛、镜像关系是否真的改变命运
- 更主动地拆“事件很强，但人物只是挂件”的方案

人物关系审判官默认更偏人物与关系高压质检，但不能忽视人物如何真正进入主线、事件和终局。

## 写作分工铁律

- Host 负责收敛，不负责包办全部初稿
- 内容席位必须持续承担具体文件主写
- 反驳者 / 终局闭环官 / 人物关系审判官必须持续承担文件级审查
- 发言长度和职责应随当前子任务自然倾斜，不要求所有席位都说一样多、一样泛

## 投票规则

- 一人一票
- 投票必须附理由
- 若票型缺失、含糊或不完整，必须先补票再计票
- Host 固定负责计票与宣布

## 平局规则

- 若平局，不能立刻机械复投
- 所有人必须先补新的观点 / 新证据 / 新取舍
- 禁止重复旧话
- 平局连续发生时，Host 必须先推动补足缺失约束或证据，再重新发起投票

## 进入 Phase 3 的质检标准

在进入 Phase 3 前，反驳者、终局闭环官、人物关系审判官至少要重点判断：
- 当前最弱一笔是否已经暴露并被正面处理
- 是否还存在明显伪强内容
- 主要文件是否已具备整合前提
- 继续留在 Phase 2 是否仍有结构性收益
