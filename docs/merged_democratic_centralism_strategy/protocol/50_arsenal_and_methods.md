# 学科武器库与方法论（精简三层版）

学科知识不是气氛装饰，也不是“说几个术语显得厉害”。  
它必须真的进入：
- 世界规则
- 诡计与骗局
- 证据链
- 误导与反制
- 角色的主场方法论

目标不是把角色写成只会一门学科的窄专家，而是让核心角色都具备跨学科联动能力，同时各自拥有 1 到 2 个最可怕的主场方法论。

## 使用铁律

1. 任何学科一旦被调用，都必须说明它具体解决什么问题。
2. 学科不能只停留在“解释设定”，而要进入胜负判定。
3. 最强的智斗优先追求三层联动：
   - 核心层打底
   - 增强层互锁
   - 杀手锏层少量精准引爆
4. 如果一个方案只会堆学科名词，却没有进入事件结构，视为伪强内容。

## 核心层（必须高频常驻）

这些学科要反复进入规则、骗局、制度、证据链、角色决策与胜负判定。

- 心理学 / 创伤与依附 / 认知偏差
  - 用来设计人格软肋、操控与反操控、情绪崩塌点、群体误判。
- 社会工程学
  - 用来设计伪装、身份借用、诱导、流程绕过、信任渗透。
- 逻辑学 / 推理学
  - 用来设计演绎、归纳、溯因、漏洞识别、证据链重构。
- 博弈论
  - 用来设计多方博弈、承诺机制、威慑、信息不对称、被迫合作。
- 信息论 / 密码学
  - 用来设计编码、信号噪声、假消息、验证机制、密钥与误导。
- 数学 / 统计 / 图论
  - 用来设计概率路径、风险评估、异常识别、结构求解、最优路径。
- 医学 / 法医 / 生理极限
  - 用来设计药理、伪现场、生理极限、残血翻盘、时间与身体限制。
- 计算机科学 / 工程 / 数字取证
  - 用来设计系统、协议、漏洞、自动化、取证与反取证。
- 经济 / 法政 / 传播 / 组织设计
  - 用来设计激励、资源配置、制度漏洞、合法性、叙事操纵与权力结构。

## 增强层（用来提升复杂度与系统感）

这些学科不是每轮都要出现，但只要进入，就应显著提高结构复杂度、压迫感与互锁强度。

- 认知科学 / 计算传播 / 计算社会科学
  - 用来设计认知战、舆论误导、群体反应和信息扩散路径。
- 复杂系统 / 控制论 / 网络科学
  - 用来设计自组织失控、系统回路、连锁反应和多层控制。
- 决策科学 / 机制设计 / 社会选择理论
  - 用来设计规则本身如何逼出最残酷或最聪明的选择。
- 因果推断 / 贝叶斯推断 / 风险科学
  - 用来设计如何在不完全信息下更新判断、赌最小风险路径。
- 行为经济 / 神经经济 / 人因工程
  - 用来设计人在高压、贪欲、恐惧、损失厌恶下的偏移与破绽。

## 杀手锏层（少量精准引爆）

这些内容只应在真正需要制造“外星感”“终局级压迫感”时精准使用，不能泛滥。

- AI 安全 / 多智能体 / 可解释 AI
  - 用来设计非人级预测、策略竞争、协同欺骗与控制问题。
- 零知识 / 隐私计算 / 可验证计算
  - 用来设计“证明了某事，但没有暴露核心内容”的规则与骗局。
- 量子信息
  - 只在能明确进入测量、验证、信息限制时使用，禁止拿来装神秘。
- 脑机接口 / 神经工程
  - 用来设计认知控制、记忆干预、感知扭曲与反制代价。
- 机器人 / 可编程材料
  - 用来设计执行层、伪装层、载体层的技术压迫感。

## 角色主场方法论要求

每个核心角色都必须尽量回答：
- 他最擅长调用哪 1 到 2 套主场方法论
- 这套方法论如何体现在他拆局、诱导、压制、反杀、翻盘的方式里
- 这套方法论为什么让他和其他聪明人不一样

如果一个角色没有自己的主场方法论，只是“也很聪明”，视为不合格。
