# 当前已实现功能清单（截至 2026-03-14）

> 说明：本文档用于记录“代码中已落地”的功能现状，避免与早期的需求/设计文档产生偏差。

## 1. 用户与安全

- 邮箱 + 密码注册/登录（注册需邮箱验证码）
- Session Cookie 登录态
- 登录失败次数限制与锁定策略
- 安全设置：修改密码（`/settings/security`）
- 角色：`user` / `admin`（可通过 `ADMIN_EMAILS` 指定管理员邮箱）

## 2. AI 配置（Agents）

- AI 配置列表与管理：创建 / 编辑 / 删除 / 复制（duplicate）
- AI 配置支持导出 / 导入（加密文件，包含 API Key；导入无需重新填写）
- 支持 Provider：`openai` / `anthropic`
- 支持测试连通性（test-config / test）
- API Key 后端加密存储、前端仅展示脱敏值

## 3. AI 文件管理（每个 AI 配置）

- VS Code 风格文件树（Tree）
- 右键菜单：新建文件 / 新建文件夹 / 删除文件 / 删除文件夹
- Tabs 多文件编辑（未保存提示）
- 拖拽文件到文件夹（移动路径）

## 4. 辩论（Debates）

 - 创建辩论：输入问题、选择至少 2 个参与 AI、设置最大轮数（支持无限）
- 运行控制：开始 / 暂停 / 恢复 / 停止
- 运行中/暂停中可追加参与者
- 每轮保存发言内容与结构化结果（JSON）；失败可重试；并记录 token 估算与耗时
- 简化共识：基于 proposed_solution / support / rebuttal / agreement_score 聚合，达到阈值可提前结束

## 5. 策略（Strategies）

- 策略页：我的策略 / 社区分享
- 策略内容：至少 2 个“角色”，每个角色包含 System Prompt + 文件
- 策略文件管理体验与 AI 文件管理一致（树/右键/Tabs/拖拽/删文件夹）
- 策略操作：新建 / 编辑 / 删除 / 分享(公开) / 取消分享 / 基于策略创建工作台
- 工作台：绑定共享策略，保存私有题目、私有素材、原始点子库与默认 AI 映射，再从工作台创建辩论
- 辩论级覆盖：策略带来的 prompt/文件以“辩论维度”覆盖，不污染全局 AI 配置

## 6. 辩论长时记忆（每场辩论）

- 参与者独立记忆（按“辩论参与者”维度）：
  - 自动维护 `memory/log.jsonl`（追加）
  - 自动维护 `memory/summary.md`（定期压缩摘要）
  - 在后续回合注入上下文（用于长辩论中途清理后恢复）
- 全场共享事实板（可选开关）：
  - 创建辩论时可选择是否开启
  - 若策略 workflow 启用了独立总结器并开启 facts board，则会把 `facts/board.md` 维护成结构化事实板，并在后续回合注入上下文

## 7. 管理与可观测性

- 健康检查：`/api/health`
- 管理员可观测性面板：`/admin/observability`

## 8. 体验与工程配置

- 顶部导航：辩论 / 策略 / AI 配置，当前页面高亮
- 构建提速：`next build` 跳过 ESLint 与 TypeScript 校验（可在 CI/本地单独跑 `npm run lint` / `tsc --noEmit`）
