当前遗留问题

1. 平台默认层已经中立，但部分历史文档仍在描述旧的小说化心智，需要继续收口成“固定角色 + workflow + prompt”的现状表达。

2. 质量门槛虽然已经升级到 `qualityChecks`，但真实策略还能继续补更锋利的判据，尤其是事件、角色、章节和终局文件的失败模式。

3. 默认 workflow 已经很轻，但复杂策略的阶段说明、输出要求和交付标准仍然偏重，需要继续控制长度与重复度，避免策略再次膨胀。

当前建议的下一步优先级：

1. 继续精简题材文档中的模式化叙述，只保留当前实现与固定角色策略。
2. 继续细化真实策略中的质量判据，优先加强事件、角色、终局相关文件。
3. 继续做策略瘦身，减少重复提示词，把高价值约束优先保留在 protocol 与 deliverable 描述里。
