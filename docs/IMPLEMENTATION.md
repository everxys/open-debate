# AI 辩论场 - 技术实现文档

## 技术栈

| 层级 | 技术选型 |
|------|----------|
| 前端 | Next.js（App Router）+ React |
| 后端 | Next.js Route Handlers / Server Actions |
| 数据库 | PostgreSQL 18（本地 Docker 或任意托管） |
| DB Driver | `pg` |
| 实时更新 | 前端短轮询（MVP） |
| AI 集成 | 服务端 Provider Adapter（OpenAI / Anthropic） |
| 认证 | 应用自有邮箱密码 + HttpOnly session cookie |
| 部署 | 本地部署（Docker Compose） |

## 系统架构（MVP）

```
┌─────────────────────────────────────────────┐
│                 用户界面层                  │
│  登录/配置页/创建辩论/控制台/结果页         │
└─────────────────────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────┐
│                 应用接口层                  │
│  Route Handlers / Server Actions            │
└─────────────────────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────┐
│                 领域服务层                  │
│  AgentService / DebateService / Runtime     │
└─────────────────────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────┐
│                 持久化层                    │
│            PostgreSQL (via pg)              │
└─────────────────────────────────────────────┘
```

## 目录结构建议

```
open-debate/
├── app/

│   └── init.sql

```

## 实现原则

1. 先打通创建、运行、展示主链路。
2. 结构化解析失败不影响整场辩论完成（回退原文）。
3. 数据访问与业务逻辑分离，写操作统一由服务层处理。
